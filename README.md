# Agrima ERP — إدارة المخزون والبكر وأذون الصرف وحجوزات العملاء

نظام ERP يعمل داخل المتصفح (PWA على GitHub Pages) بواجهة عربية RTL بطراز مؤسسي، متصل بقاعدة **Supabase** مع مزامنة تلقائية أونلاين/أوفلاين، ونظام دخول وصلاحيات (مدير نظام / أمين مخزن) مفروضة على مستوى قاعدة البيانات عبر RLS.

> هذا إصدار **v11-cloud-r1**: كل وظائف وبيانات النسخ السابقة محفوظة حرفيًا (IndexedDB v3 → v4 ترحيل إضافي بحت) + طبقة سحابة كاملة: Supabase Auth، مزامنة Local-first بمعرفات ثابتة وعظام قبر ومنع تعارض بالأحدث، إدارة مستخدمين من داخل التطبيق عبر Edge Function آمنة، وبث Realtime للتحديث اللحظي.

## التشغيل

```bash
# فحص محلي
python3 -m http.server 8080
# ثم: http://localhost:8080

# الاختبارات الآلية (51 اختبارًا: المحرك + طبقة السحابة والصلاحيات)
npm install && npm test
```

أو انشر المجلد كما هو على GitHub Pages / أي استضافة ثابتة.

## التهيئة السحابية (مرة واحدة)

دليل نشر كامل خطوة بخطوة في **`docs/DEPLOY_SUPABASE.md`**:
تشغيل `sql/01_schema.sql` ثم `02_rls_policies.sql` ثم `03_functions.sql` من SQL Editor،
نشر `supabase/functions/admin-create-user`، وإنشاء أول مدير نظام —
وبعدها كل إدارة المستخدمين (إضافة/تأكيد بريد تلقائي/أدوار/إيقاف) من داخل التطبيق دون فتح لوحة Supabase.

## الأدوار والصلاحيات

- **مدير النظام:** كل الأقسام والعمليات (إضافة/تعديل/حذف/اعتماد/تقارير/مستخدمون/إعدادات/نسخ احتياطي).
- **أمين المخزن:** عرض الرصيد الحالي المتاح + أذون اليوم والأمس (بتوقيت القاهرة) + طباعتها + **إنشاء إذن صرف جديد** (مسودة حتى اعتماد المدير) — يُفرض بسياسات RLS لا بإخفاء أزرار فقط.
- **وضع محلي (دون إنترنت فقط):** يعمل على بيانات الجهاز كما في الإصدارات السابقة بلا مزامنة.

## ما الجديد في v10 (محفوظ كما هو)

1. **تصميم ERP كامل:** قائمة جانبية مجمّعة (الرئيسية / العمليات / الإدخال / البيانات / الإدارة) بأيقونات SVG خطية، شريط علوي، بطاقات أرقام بلمسات حالة، جداول موحدة (نفس تصميم الشاشة هو نفسه للطباعة)، بحث وتصفية وفرز — بلا زخارف.
2. **كل وظائف النسخ السابقة محفوظة:** لوحة التحكم، الرصيد الحالي، تسجيل البكر، إدارة الرولات والبكر، سجل الإنتاج (عرض فقط)، أذون الصرف بمسودة/اعتماد وترقيم ضريبي/غير ضريبي، حجوزات العملاء، سجل حركات الصرف، العملاء، الأصناف، 9 تقارير A4، الاستيراد والتصدير، النسخ الاحتياطي، الإعدادات.
3. **محرك الحسابات دون تغيير:** الرصيد = مجموع (إضافة − صرف) لكل (صنف، جرام، مقاس) مع بُعد وزن البكرة — مطابق لملف الإكسل الأصلي، ومفحوص آليًا.
4. **طباعة A4:** إذن الصرف من اللقطة المحفوظة نفسها، تكرار ترويسة الجداول في كل الصفحات، أماكن توقيعات.
5. **العمل دون إنترنت:** Service Worker يخزّن كل ملفات التطبيق محليًا — يعمل بلا اتصال ويخزن البيانات على جهازك.
6. **متجاوب:** جوال 375px حتى الشاشات الكبيرة، جداول الجوال تتحول لبطاقات مقروءة.

## الأمان والنسخ الاحتياطي

- البيانات تُخزن على جهازك فقط (IndexedDB) — لا تُرسل لأي خادم.
- كل عملية حذف/تعديل مسجلة في سجل تدقيق محلي (قبل/بعد) ولا تُعدل السجلات التاريخية بصمت.
- خذ نسخة احتياطية دورية من قسم «النسخ الاحتياطي» (ملف JSON يغطي كل المتاجر مع فحص مخطط قبل الاستعادة).
